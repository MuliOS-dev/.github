**An independent Linux distribution built around choice, performance, and personalization.**

*People change, your OS too.*

MuliOS adapts packages, tools, and performance settings to how you use your computer,<br>
through switchable **profiles** rather than a separate OS for every use case.

---

## Profiles

| Profile | Focus |
| --- | --- |
| **Game Focused** | Gaming software and optimizations |
| **Code** | Development tools and environments |
| **AI** | AI and machine-learning workloads |
| **Study** | School and everyday study work |
| **Privacy** | Privacy-focused configuration |
| **Casual** | Balanced everyday setup |

More profiles will come as the project evolves.

Releases and current instructions: [MuliOS-Arch](https://github.com/MuliOS-dev/MuliOS-Arch)

## Updates

**MUpdate** syncs MuliOS system components with the official repository:<br>
GitHub blob verification, automatic backups, dry-run and force modes, desktop/theme sync, and self-updating.<br>
It currently targets the Arch edition. See the [MUpdate repository](https://github.com/MuliOS-dev/update).

*Back up important personal data before major system changes or updates.*

## Security

*Security is handled by our custom Security module MShield.*

**MShield** is an experimental Linux Security Module for MuliOS.
The first version adds kernel-enforced controls for process tracing (ptrace).
It is intentionally narrow; future policy areas should be added only with a clear threat model and tests.
See the [MShield repository](https://github.com/MuliOS-dev/MShield).

*MuliOS's MShield is deployed with the GPL 2.0 license*
